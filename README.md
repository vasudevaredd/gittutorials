# My Git Learning Project

This repository is created while learning Git and GitHub.

## About
I am practising basic Git commands and learning how to manage project files using version control.

## Git Commands Practised
- `git init` — initialise a Git repository
- `git status` — check the working-tree status
- `git add .` — stage changes
- `git commit -m "message"` — save a commit
- `git log` — view commit history
- `git branch` — list branches
- `git push` — upload commits to a remote repository
- `git pull` — download and integrate remote changes

## Getting Started
1. Open Command Prompt in your project folder.
2. Initialise Git:
   ```bash
   git init
   ```
3. Stage the README:
   ```bash
   git add README.md
   ```
4. Create your first commit:
   ```bash
   git commit -m "Add README file"
   ```
